Mini-redisJuly 2026
  • Built a Redis-compatible key-value store from scratch in Python with a custom RESP protocol parser, thread-per-connection concurrency, and TTL-based expiration; verified correctness against the real redis-cli client
  • Sustained ~70,000 ops/sec across 20 concurrent client connections in a custom benchmark hammering the server with a mixed SET/GET/INCR workload
  • Hand-written incremental RESP parser that handles partial/fragmented TCP reads, buffering incomplete frames and resuming parsing as more bytes arrive rather than assuming one recv() equals one command
  • Dual expiration strategy — lazy checks on every read plus a background reaper thread doing active sweeps on an interval — the same pattern real Redis uses to avoid unbounded memory growth from keys nobody reads again
